3. Planning Phase — Organization & Staffing

3.1 RACI Deliverable Matrix (New Widget)

A brand-new RaciDeliverableMatrix widget (1,455 lines) was created and integrated into the OrganizationPlanSubsectionsScreen. This matrix provides:

  • Deliverable Rows: Every sidebar deliverable from Planning Phase through Launch Phase, with a frozen left column showing deliverable name + phase chip.
  • Role Columns: One column per role from the Staffing Plan, with named personnel displayed under each role header.
  • RACI Cell Assignment: Coloured RACI pills (R / A / C / RV / I / V) with tap-to-edit dropdowns and empty dashed pills for unassigned cells.
  • Role-based Inheritance: Assignments are keyed by role title (lowercased) — when a role is reassigned, the new person automatically inherits all cells.
  • Approval Workflow: An approval banner with stakeholder-alignment confirmation text. Edits reset approval status. Approval is persisted with approver name, role, and timestamp.
  • Full-Screen View: Expandable via FullScreenTableWrapper.

3.2 Staffing Plan Screen Enhancements

The OrganizationPlanSubsectionsScreen (6,647 lines) received substantial additions including the RACI matrix integration, PDF export capability (_exportPlanningSubsectionPdf), and AI-powered staffing suggestions. The screen now includes:

  • Staffing Plan table with all personnel allocation columns (Position, Name, Location, Employment, Category, Start/Release Dates, NDU Access, Status)
  • Reminder banners for overdue/upcoming mobilizations and releases
  • AI suggestion engine for NDU Project Access based on subscription tier and project scope
  • Tabbed view: Staffing Plan, Staffing Timeline Gantt, and Estimated Cost tab

3.3 Cost by WBS Tab (Complete Rewrite)

The CostByWBSTab widget (1,171 lines) was completely rewritten as a "world-class dashboard" showing costs per WBS level. Key design decisions:

  • Single source of truth via WBSProvider.computeCostRollup — does NOT re-walk cost estimates
  • Cost matching by costLineIds OR wbsRef == node.code, with rolled-up totals including descendant nodes
  • Schedule linkage surfaced per L1 row (planned start / finish / status from WbsLinkageService)
  • Doubles as a "scope ↔ cost ↔ schedule" traceability matrix at a glance

3.4 WBS Module Screen Refactor

The WBSModuleScreen was significantly refactored (946 lines, down from larger size). Changes include:

  • Standardised on ResponsiveScaffold with InitiationLikeSidebar for consistent navigation
  • Horizontal TabBar at the top (light-mode pills matching Project Controls screen), replacing the old dark navy left rail
  • ContextBanner showing upstream Initiation Phase context (project name, solutions count, business case preview)
  • Integrated CostByWBSTab as a first-class tab alongside Builder, AI Generator, and Validator
